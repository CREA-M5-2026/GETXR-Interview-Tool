# GETXR Interview Tool

Guide for TAs running the (M)GETXR Week 9 code review interviews. Embedded in the course staff Notion page.

- `index.html` – the guide (timer, interview flow, outcome, one copy for Notion, reference)
- `decks.js` – the check cards per assignment; edit this file to add or change cards

No student data is stored here or in the browser.
